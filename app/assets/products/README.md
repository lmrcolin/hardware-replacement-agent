# Fotos de producto

Fotos reales de Wikimedia Commons con licencia libre, reducidas a 480 px (JPEG). Cada una conserva
su licencia original; la app muestra autor, licencia y enlace bajo la foto. `sources.json` es el
manifiesto que lee `app/components/images.py`. Las piezas sin foto aquí usan una ilustración
vectorial por factor de forma.

Para añadir una foto: `<PART_NUMBER>.jpg` (o .png/.webp) y su entrada en `sources.json`.
